# 📚 Library Management System

A web-based **Library Management System** built using **Django** and **Django REST Framework (DRF)**. The application simplifies library operations by providing features for managing books, members, borrowing, and returning books through a user-friendly interface and RESTful APIs.

---

## ✨ Features

- User Authentication
- Book Management (Add, Update, Delete)
- Member Management
- Book Borrow & Return
- Search and Filter Books
- RESTful API with Django REST Framework
- Responsive User Interface

---

## 🛠️ Tech Stack

- **Backend:** Django, Django REST Framework
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite
- **Tools:** Git, GitHub

---

## 🚀 Installation

```bash
# Clone this repository

# Navigate to the project
cd library-management-system

# Create a virtual environment
python -m venv venv

# Activate the virtual environment

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

# Run Backend
cd backend

# Apply migrations
python manage.py migrate

# Run the development server
python manage.py runserver

# Run Frontend
cd frontend

# Apply migrations
python manage.py migrate

# Run the development server
python manage.py runserver
```

## 📌 API

The project uses **Django REST Framework** to expose RESTful APIs for managing books, members, and library operations.
